Systems of equations
Solutions at a glance
For a₁x+b₁y=c₁ and a₂x+b₂y=c₂:

One solution: different slopes (lines cross)
No solution: a₁/a₂ = b₁/b₂ ≠ c₁/c₂ (parallel lines)
Infinite solutions: a₁/a₂ = b₁/b₂ = c₁/c₂ (same line)

Methods: substitution (isolate one variable) or elimination (add/subtract equations to cancel a variable).

Inequalities & Absolute Value
Inequalities
The sign flip rule
Flip the inequality sign when multiplying or dividing both sides by a negative number.

−3x + 7 ≤ 1 → −3x ≤ −6 → x ≥ 2 (sign flipped when dividing by −3)

Graphing: open circle = strict (< or >), closed circle = inclusive (≤ or ≥).
Forgetting to flip the sign when dividing by a negative — the #1 inequality error.
Absolute value
Always two cases
|ax + b| = c gives two equations:
ax + b = c   AND   ax + b = −c

|x| < a → −a < x < a (AND)
|x| > a → x < −a OR x > a

Distance on number line: |a − b| = distance between a and b.
Setting up only one case for an absolute value equation instead of two.
f(x)
Functions
TransformationEffect on graphKey trap
f(x) + kShifts UP by kPositive k = up. Negative k = down.
f(x + h)Shifts LEFT by hThis is the most frequently missed. f(x+3) shifts LEFT 3 — because you need x+3=0, so x=−3.
f(x − h)Shifts RIGHT by hf(x−3) shifts right 3. Think: x−3=0 gives x=3.
−f(x)Reflects over x-axisAll y-values negate. Minimum becomes maximum and vice versa.
f(−x)Reflects over y-axisAll x-values negate. Even functions satisfy f(−x)=f(x).
a·f(x), a>1Vertical stretchMultiplies all y-values by a. Steeper/taller graph.
a·f(x), 0<a<1Vertical compressionShrinks the graph toward the x-axis.
Composite functions
Inside out, always
f(g(x)): apply g first, then apply f to the result.

f(g(3)): Step 1 → calculate g(3). Step 2 → use that answer as the input to f.

Never apply f first. The inner function always runs first regardless of which letter comes first alphabetically.
Applying f first in f(g(x)) instead of g first.
Inverse functions
Swap and solve
To find f⁻¹(x): replace f(x) with y, then swap x and y, then solve for y.

f(x) = 3x−1 → y = 3x−1 → x = 3y−1 → y = (x+1)/3
So f⁻¹(x) = (x+1)/3

f(f⁻¹(x)) = x always.
Domain of f⁻¹ = Range of f.
f(f⁻¹(8)) = 8 always (they cancel). f⁻¹(f(8)) = 8 always.

Quadratic Equations
~4–6 questions
Standard form
ax² + bx + c = 0
Use when: factoring, quadratic formula, finding discriminant.

Quadratic formula:
x = (−b ± √(b²−4ac)) / 2a

Sum of roots = −b/a
Product of roots = c/a

Axis of symmetry: x = −b/2a
In the quadratic formula, the entire expression 2a is in the denominator — not just a.
Vertex form
a(x − h)² + k
Use when: vertex, axis of symmetry, max/min.

Vertex = (h, k)
Axis of symmetry = x = h

a > 0 → opens up, minimum at vertex
a < 0 → opens down, maximum at vertex

Complete the square: x²+bx = (x+b/2)² − (b/2)²
In a(x−h)²+k, the vertex is (h, k) not (−h, k). The sign flips: (x−3)² has vertex x=3.
Factored form
a(x − r₁)(x − r₂)
Use when: roots/zeros, x-intercepts.

Roots at x = r₁ and x = r₂

Special products:
a²−b² = (a+b)(a−b)
a²+2ab+b² = (a+b)²
a²−2ab+b² = (a−b)²

Vertex x-coord = midpoint of roots: (r₁+r₂)/2
x²−5x+6 = (x−2)(x−3). Roots: x=2 and x=3. Vertex at x=2.5.
Discriminant
b² − 4ac tells you everything
> 0: two distinct real roots (line intersects parabola twice)
= 0: exactly one real root — tangent (repeated root)
< 0: no real roots (never crosses x-axis)

One solution → discriminant = 0 → b²−4ac = 0 → solve for the unknown.

SAT question type: "For what value of k does kx²+bx+c = 0 have exactly one solution?"
kx²−8x+4=0: one solution → 64−16k=0 → k=4.
Parabola symmetry
The symmetry shortcut
A parabola is symmetric about its axis x = −b/2a.

If f(k) = f(k+d), then k and k+d are equidistant from the axis. The midpoint of k and k+d equals the axis.

(k + k+d)/2 = −b/2a → solve for k

This avoids expanding and setting equal — much faster.
Trying to solve f(k)=f(k+d) by expanding — use the symmetry shortcut instead.

Polynomials & Rational Functions
Factor theorem
Roots and factors
If p(a) = 0, then (x−a) is a factor of p(x).

To find the third root of a cubic with two known roots: the constant term = (−1)³ × a × b × c (product of roots with sign adjustment based on leading coefficient).

Use polynomial long division or synthetic division to factor out a known root.
p(x) = x³+ax²+bx−8 with roots 1 and −2. Product of roots = 8/1 = 8. Third root: 8 / (1×(−2)) = −4. Wait: product = (c/a) with sign, so product = −8/1=−8 → 1×(−2)×r = −8 → r=−4.
Rational functions — holes vs asymptotes
The crucial distinction
Vertical asymptote: denominator = 0 and the factor does NOT cancel
Hole (removable discontinuity): the same factor appears in numerator AND denominator — it cancels, but the value is still excluded from the domain

(x²−4)/(x−2) = (x+2)(x−2)/(x−2) = x+2, but x≠2. There is a hole at x=2, not an asymptote.
Cancelling a factor and assuming x=2 is now allowed. The restriction survives simplification.

The exponent structure trap — most common advanced math error
If a quantity doubles every 3 years, the model is y = a·2^(t/3), NOT y = a·2ᵗ. The denominator in the exponent controls the rate. Always check: does the exponent equal 1 when t equals the stated period? If doubling every 3 years, at t=3: 2^(3/3) = 2¹ = 2 ✓. At t=3 with wrong model: 2³ = 8 ✗.

Functional Equations & Recursive Patterns
Functional equations
Chaining the rule
If g(2x) = 4·g(x): doubling x multiplies the output by 4.

g(3) = 5 → g(6) = 4·g(3) = 20 → g(12) = 4·g(6) = 80

Always build step by step. Don't try to jump multiple steps at once — chain each application of the rule.
Trying to calculate g(12) directly from g(3) in one step instead of chaining through g(6).
Systems with unknowns in coefficients
No solution / infinite solutions setup
"The system has no solution" → parallel lines → same slope, different intercept.

Multiply one equation by k to match the other's coefficients, then check what value of the unknown satisfies the slope match but not the intercept match.

"The system has infinite solutions" → same equation → ALL ratios equal.
3x−2y=7 and 6x−ky=10. No solution: coefficients must match → k=4. Check: 14≠10 ✓ (no solution confirmed).

Descriptive Statistics
MeasureDefinitionKey traps
MeanSum of all values ÷ countSensitive to outliers. A single extreme value can dramatically shift the mean.
MedianMiddle value (odd n) or average of two middle values (even n)Resistant to outliers. If n is even, average the two middle values.
ModeMost frequently occurring valueA data set can have 0, 1, or multiple modes. Not affected by outliers.
Standard DeviationMeasures spread (variability) around the meanAdding a constant to all values → mean changes, SD unchanged. Multiplying by k → both mean and SD multiply by k.
RangeMax − MinHighly sensitive to outliers — one extreme value changes it completely.
IQRQ3 − Q1Measures spread of middle 50%. Resistant to outliers.
Outlier ruleValue is outlier if: > Q3 + 1.5×IQR or < Q1 − 1.5×IQRBeing above the maximum does NOT automatically make something an outlier — you must apply the 1.5×IQR rule.
Weighted averageΣ(value × weight) / Σ(weights)When groups have different sizes, you cannot just average the group means.
Standard deviation — the key insight
What changes it, what doesn't
SD measures spread. It is not affected by shifting the entire dataset up or down.

Adding 5 to every value: mean goes up 5, SD stays the same
Multiplying every value by 2: mean doubles, SD doubles
Both operations: multiply by 2 then add 5 → SD multiplied by 2 only

Think of it this way: adding a constant moves everyone equally — the gaps between values don't change.
Adding 5 to the standard deviation when a constant is added to all values.

Five numbers: Min · Q1 · Median · Q3 · Max

The box spans Q1 to Q3 (the IQR). The line inside the box is the median. Whiskers extend to min and max.

Skewed right: median closer to Q1, long right whisker
Skewed left: median closer to Q3, long left whisker
Symmetric: median in the middle of the box

Correlation, Causation & Study Design
The most-tested conceptual trap in all of data analysis
Correlation ≠ causation. No matter how strong the correlation (r = 0.99), an observational study cannot establish causation. Only a controlled experiment with random assignment permits a causal conclusion. Lurking variables — unmeasured third factors — may drive both variables simultaneously.
Study types
What each can conclude
Observational study (survey, existing data): can show association/correlation only. NEVER causation.

Controlled experiment with random assignment: can conclude causation — randomisation balances lurking variables across groups.

Key signal words: "randomly assigned" → causation allowed. "Surveyed" / "observed" / "found that" → correlation only.
Reading "strong correlation" and concluding that one variable CAUSES the other.
Sampling & margin of error
Generalising results
Random sample → results can be generalised to the population
Convenience sample → results cannot be generalised

Margin of error (MOE): represents uncertainty in the estimate.
If poll says 54% ± 4%, the true value is likely between 50% and 58%.

MOE ∝ 1/√n
Sample ×4 → MOE ÷2 (halves)
Sample ×9 → MOE ÷3 (thirds)
Dividing MOE by 4 when sample quadruples — it should be divided by √4 = 2.

Probability
Core probability rules
Formulas
P(A and B) = P(A) × P(B) [if independent]
P(A or B) = P(A) + P(B) − P(A and B)
P(A or B) = P(A) + P(B) [if mutually exclusive]

Conditional probability:
P(A|B) = P(A and B) / P(B)

Two-way table: P(A|B) uses B's total as denominator, not grand total.
Using the grand total as the denominator for a conditional probability question. Always check: "given that...?" → use that group's total.
With vs without replacement
The denominator changes
WITH replacement: each draw is independent — same denominator each time.
5 red of 10: P(red) = 5/10 both times. P(both red) = (5/10)² = 1/4

WITHOUT replacement: denominator decreases after each draw.
P(1st red) = 5/10. P(2nd red | 1st red) = 4/9.
P(both red) = 5/10 × 4/9 = 20/90 = 2/9
Using the same denominator for both draws in a without-replacement problem.

Scatterplots, Lines of Best Fit & Models
Line of best fit
Interpreting the equation
y = mx + b where x = predictor, y = predicted outcome

Slope (m): for each 1-unit increase in x, y changes by m
Intercept (b): predicted value of y when x = 0

To predict: substitute x into the equation. To find x for a given y: substitute y and solve.

Note: predictions beyond the range of the data (extrapolation) are unreliable.
Confusing the slope with the intercept when reading the equation.
Percentages, ratios & unit conversion
Unit analysis
Set up unit conversions as fractions that cancel:
60 mi/hr × 5280 ft/mi × 1 hr/3600 s = 88 ft/s

Compound percent change: two successive 10% increases ≠ 20%. It's (1.1)(1.1) = 1.21 = 21% total.

Part/whole ratio: if ratio of A:B = 3:5, then A = 3/8 of total and B = 5/8 of total.
Adding successive percentage changes instead of multiplying the growth factors.

Circles
All circle formulas
Know all of these cold
Area: A = πr²
Circumference: C = 2πr
Arc length: (θ/360) × 2πr
Sector area: (θ/360) × πr²

All of these use radius, not diameter. If given diameter d, then r = d/2.
Using the diameter in the formula instead of the radius. Always halve the diameter first.
Circle equation — complete the square
Standard form: (x−h)²+(y−k)²=r²
Centre = (h, k). Radius = √(right side).

From general form x²+y²+Dx+Ey=F:
Group x terms and y terms. Add (D/2)² and (E/2)² to BOTH sides.

x²−6x+y²+8y=11:
Add 9 and 16 to both sides:
(x−3)²+(y+4)²=36 → centre (3,−4), r=6
Adding (D/2)² to the left side but forgetting to add it to the right side too.

Trigonometry
SOH-CAH-TOA
The foundation
sin θ = opposite / hypotenuse
cos θ = adjacent / hypotenuse
tan θ = opposite / adjacent = sin θ / cos θ

To find a side: multiply the trig ratio by the hypotenuse (or divide).

Given tan θ = 4/3: opp=4, adj=3, hyp=5 (3-4-5 triple). sin θ = 4/5, cos θ = 3/5.
Angle B=53°, adj=9. cos 53°≈0.602. hyp = 9/0.602 ≈ 14.95.
Quadrant signs — MUST memorise
ASTC — All Students Take Calculus
QI (0°–90°): All positive (sin+, cos+, tan+)
QII (90°–180°): Sin positive only
QIII (180°–270°): Tan positive only
QIV (270°–360°): Cos positive only

If θ is in QII and sin θ = 3/5: adj is NEGATIVE (−4), so cos θ = −4/5 and tan θ = −3/4.
Getting the right ratio magnitude but the wrong sign because the quadrant was ignored.
Key trig identities
Tested on every exam
Pythagorean identity: sin²θ + cos²θ = 1
Therefore: sin²θ = 1 − cos²θ and cos²θ = 1 − sin²θ

Co-function identities:
sin(90°−θ) = cos θ
cos(90°−θ) = sin θ

Supplementary angle: sin(180°−θ) = sin θ
sin²θ/(1−cos²θ) = sin²θ/sin²θ = 1. Always simplify using sin²θ+cos²θ=1 first.
Side ordering in triangles
Angles control sides
In any triangle: the largest angle is opposite the longest side.

To order sides: find all three angles first. Then assign: smallest angle → shortest opposite side, etc.

If A=35°, B=80°, then C=65°. Order of angles: A<C<B. So sides: a<c<b.
Confusing which side is opposite which angle — side a is opposite angle A (not adjacent to it).

Angles, Polygons & Parallel Lines
Polygon angle formulas
Sum and each interior angle
Sum of interior angles of n-gon = (n−2) × 180°

Triangle: 180° · Quadrilateral: 360° · Pentagon: 540°
Hexagon: 720° · Octagon: 1080°

Each interior angle of a regular n-gon = (n−2)×180° / n

Each exterior angle of any regular n-gon = 360° / n
Regular hexagon: each interior = 720/6 = 120°. Each exterior = 360/6 = 60°.
Parallel lines & transversals
Angle relationships
When a transversal crosses parallel lines:

Alternate interior angles: equal (Z-shape)
Corresponding angles: equal (F-shape)
Co-interior / same-side interior: supplementary (= 180°)

Vertical angles: always equal (any two intersecting lines)
Supplementary angles: sum to 180°
Complementary angles: sum to 90°
Confusing alternate interior (equal) with co-interior (supplementary) angles.

Question approach — every question
The 4-step method that prevents most errors
1. Read the question twice. What exactly is being asked? (Not what you think it's asking.) 2. Identify the concept being tested. Is this a systems question? A trig identity? A quadratic? 3. Work the problem. Write every step — no mental arithmetic on multi-step problems. 4. Verify the answer. Does it make sense? Plug it back in. Check units.
Common trap types
The SAT's favourite tricks
Off-by-one: "how many years until less than 40%?" — check year 4 AND year 5, not just one.

Wrong quantity: answer asks for y but you solved for x.

Missing constraint: absolute value has two solutions; only pick the one that fits all conditions.

The halfway answer: for multi-step problems, one choice is always the answer to step 1 — not the final answer.

"Cannot be determined": if you get different answers with different valid assumptions, this is correct.
Strategies for hard questions
When the algebra looks messy
Plug in the answers: for "which value satisfies this equation," try the choices directly — fastest method.

Plug in numbers: for abstract algebra questions, assign a specific value to variables and test which answer choice works.

Draw it: geometry questions — always sketch. Label what you know. You often see the solution.

Look for patterns: ugly numbers often hide a Pythagorean triple or a factoring shortcut.
