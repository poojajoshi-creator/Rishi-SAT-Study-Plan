Add · Delete
Revise & Placement
Four related question types that test whether sentences belong in a passage, where they belong, and whether they need to be changed. The single deciding test: does this serve THIS paragraph's specific main point?
~2–4 per moduleTarget: 60 secRule: main point first, then decide
✂️
Four question types, one underlying rule
Step 1
The four types

Add: "Should the following sentence be added here?" Or: "Which sentence, if added, would best accomplish [goal]?"

Delete: "The student is considering deleting the underlined sentence. Should it be kept or deleted?"

Placement: "Where in the paragraph should sentence X be placed — at position A, B, C, or D?"

Revise: "Which choice best completes the sentence?" or "Which revision of the underlined portion best accomplishes [stated goal]?"

The single rule governing all four types

Before answering ANY of these questions, complete this sentence:

"The main point of this paragraph is: ___."

Then ask: "Does this sentence / position / revision directly serve that main point?"

If yes → add it / keep it / place it there / use that revision.
If no → don't add it / delete it / don't place it there.

The trap that kills students: "This sentence is interesting, accurate, and related to the topic." That is NOT the standard. The standard is whether it directly serves THIS paragraph's specific main point.

⭐
Strategy for each type
Step 2
Add
Read the passage around the insertion point. State the main point. Ask: does the new sentence directly serve that main point? If a specific goal is stated, check whether the sentence accomplishes that goal. "Yes if..." answers are usually wrong — the sentence either serves the point or it doesn't.
Delete
Apply the deletion test: "What would the paragraph lose if this sentence were removed?" If the answer is "nothing essential to the main point" → delete. If the answer is "important evidence or explanation" → keep. "Interesting but not central" → delete.
Place
Read the sentence to be placed. Identify what it requires (a set-up) and what it provides (context for what follows). It must come AFTER the idea it refers back to and BEFORE the idea it introduces. Try each position and see which one makes the paragraph logically coherent.
Revise
If a goal is stated, treat it exactly like rhetorical synthesis — goal first, then match. If no goal is stated, read for logical flow, precision, and avoidance of redundancy. The correct revision is usually the most direct and specific version.
⚠️
The traps
Step 3
Trap 1 — the most costly
"Interesting and related" ≠ keep
The sentence is factually true and about the same topic as the paragraph. Students keep it. But if it doesn't serve the specific main point, it should be deleted. Topic relevance is NOT the standard.
Paragraph: why urban heat islands form. Sentence: "The first urban heat island study was conducted in London in 1810." True, related — but it doesn't explain the mechanism. Delete.
Trap 2
The "adds detail" justification
Wrong answer for keep: "It adds important detail about the topic." Correct question: does the detail serve the main point? Extra detail that doesn't advance the argument = delete.
Trap 3
Placement: pronoun before antecedent
If the sentence refers to "it" or "this," the thing "it" refers to must appear BEFORE the sentence. Common placement error: placing a sentence that uses "this discovery" before the discovery is mentioned.
Trap 4
Add: "fits the theme" but not the point
The new sentence is about the same general subject as the paragraph. But the paragraph has a specific point, and the new sentence addresses a different aspect of the subject. Specific point ≠ general subject.

Worked examples
Step 4
Example 1 — Delete decisionMedium
Urban heat islands form when cities replace natural surfaces with heat-absorbing materials such as asphalt, concrete, and dark rooftops. These materials absorb solar radiation during the day and release it slowly at night, keeping city temperatures elevated long after sunset. [The concept of urban heat islands was first described by Luke Howard, a nineteenth-century amateur meteorologist who studied temperature differences between London and its surrounding countryside.] As a result, urban residents are exposed to consistently higher temperatures than those in surrounding rural areas, increasing risks of heat-related illness during warm months.
💭 Thinking
Main point: how urban heat islands form (mechanism) and their health consequences. Does the underlined sentence serve that point? It describes the historical origin of the concept — true, related to the topic, but it doesn't explain the mechanism or the health risk. Deletion test: what would the paragraph lose? The mechanism explanation and health consequence are complete without the Howard sentence. → Delete.
Should the underlined sentence be kept or deleted?
  • A. Kept, because it provides historical context that helps explain how the concept of urban heat islands developed.
  • B. Kept, because Luke Howard's work is an important part of the scientific understanding of urban temperature.
  • C. Deleted, because the paragraph's focus is on the mechanism by which heat islands form and their health consequences, not on the history of the concept.
  • D. Deleted, because Luke Howard's findings have been superseded by modern research.
Answer: C. The paragraph explains mechanism + health consequence. The Howard sentence is historical background — interesting but not serving the main point. A (historical context helps explain the concept) — but the paragraph isn't about explaining the concept's origins; it's about the mechanism. D invents a claim (superseded by modern research) not supported by the passage. Always delete when the reason is "serves a different purpose than this paragraph's main point."
Example 2 — PlacementMedium
[A] Scientists have long known that certain deep-sea fish produce their own light through bioluminescence. [B] The anglerfish, for example, uses a bioluminescent lure to attract prey in environments where sunlight never penetrates. [C] Researchers recently discovered that dragonfish produce a special type of chlorophyll-based pigment in their eyes that allows them to detect this red-shifted light, giving them a visual advantage over prey that cannot see it. [D] Most bioluminescent animals emit blue-green light, but dragonfish emit far-red light invisible to most deep-sea species.
Where should the following sentence be placed? "This unusual red light makes dragonfish both hard to detect and effective hunters, since their prey cannot see them approaching."
  • A. Position A
  • B. Position B
  • C. Position C
  • D. Position D (at the end)
Answer: D. The new sentence says "this unusual red light" — it refers back to dragonfish red light, which is introduced in the [D] sentence ("dragonfish emit far-red light"). The new sentence must come AFTER [D] to have an antecedent for "this unusual red light." At A or B — "red light" hasn't been mentioned yet. At C — the passage is discussing the dragonfish's eyes, not its red light emission. Only after [D] does "this unusual red light" have a clear referent.
Example 3 — Add decision with stated goalHard
Antibiotic resistance is emerging as one of the most serious threats to global public health. The WHO estimates that by 2050, drug-resistant infections could cause 10 million deaths annually — more than cancer currently does. The problem is driven by overuse and misuse of antibiotics in both human medicine and livestock farming, which accelerates the evolution of resistant bacterial strains. Coordinated global action — including stricter prescribing guidelines, reduced agricultural use, and investment in new antibiotic development — will be essential.
A student wants to add the following sentence to strengthen the paragraph's argument for coordinated action: "In 2019, the G7 nations pledged to halve their antibiotic use in agriculture by 2030 as part of an international agreement." Where should it be placed?
  • A. After the first sentence, to establish the severity of the problem
  • B. After the second sentence, to provide additional statistical evidence
  • C. After the third sentence, to illustrate how agricultural antibiotic use is driving resistance
  • D. After the final sentence, to provide a real-world example of the coordinated action being called for
Answer: D. The stated goal: strengthen the argument FOR coordinated action. The G7 pledge IS an example of coordinated action. It belongs after the final sentence, which calls for coordinated action — the G7 example then shows it has already begun. At A — the paragraph hasn't argued for coordinated action yet. At B — the sentence isn't statistical evidence for the problem's severity. At C — the G7 pledged to reduce agricultural use, so there's a partial fit, but the goal is to strengthen the argument for coordinated action, which the final sentence introduces. D is the most logical and goal-consistent placement.

Practice — 5 questions
Step 5
Practice 1 — Delete
Photosynthesis is the process by which plants convert sunlight into chemical energy stored as glucose. The reaction occurs in chloroplasts — organelles found in plant cells that contain the pigment chlorophyll. Chlorophyll absorbs primarily red and blue wavelengths of light, reflecting green wavelengths, which is why most plants appear green. [Charles Darwin conducted extensive experiments on plant movement and sensitivity to light in the late nineteenth century, publishing his findings in "The Power of Movement in Plants" in 1880.] The glucose produced through photosynthesis provides the energy plants need for growth, reproduction, and all other cellular processes.
Should the underlined sentence be kept or deleted?
  • A. Kept, because Darwin's work on plant biology is relevant to the topic of photosynthesis.
  • B. Kept, because it provides important historical context for understanding plant science.
  • C. Deleted, because the paragraph explains how photosynthesis works, and Darwin's experiments on plant movement are not part of that explanation.
  • D. Deleted, because Darwin's findings were later disproven by modern plant scientists.
C. Main point: how photosynthesis works (mechanism → chloroplasts → chlorophyll → glucose). Darwin's experiments on plant MOVEMENT are a completely different topic — not about photosynthesis. True, interesting, related to plant biology broadly — but doesn't serve this paragraph's specific mechanism explanation. A and B both use the "related to the topic" justification — the trap. D invents a claim about Darwin being disproven.
Practice 2 — Placement
[A] The discovery of penicillin by Alexander Fleming in 1928 revolutionised medicine. [B] Fleming noticed that a mould (Penicillium notatum) had contaminated a petri dish and was killing the surrounding bacteria. [C] Despite this promising discovery, penicillin was not developed into a usable medicine until the 1940s, when Howard Florey and Ernst Chain successfully purified and mass-produced it. [D] Fleming received the Nobel Prize in 1945.
Where should the following sentence be placed? "This observation led Fleming to hypothesise that the mould was producing a substance with antibacterial properties."
  • A. Position A
  • B. Position B (after the mould observation sentence)
  • C. Position C
  • D. Position D
B. "This observation" refers to Fleming noticing the mould killing bacteria — described in sentence [B]. The new sentence must come AFTER the observation it refers to. At A — the observation hasn't happened yet. At C or D — "this observation" is too far in the past; the sentence logically follows immediately from [B] and bridges to the development gap explained in [C].
Practice 3 — Add
Citizen science programmes — research initiatives that recruit members of the public to collect or classify data — have significantly expanded scientific capacity in fields such as astronomy, ecology, and ornithology. These programmes can mobilise thousands of volunteers simultaneously, generating datasets far larger than any single research team could produce. They also improve public engagement with science and give participants a genuine sense of contribution to knowledge.
The student wants to add the following sentence: "The Audubon Society's Christmas Bird Count, begun in 1900, is one of the oldest and largest citizen science programmes, having recorded bird population data across North America for over a century." Should it be added, and if so, where?
  • A. Yes, before the first sentence, because it introduces citizen science to the reader.
  • B. Yes, after the second sentence, because it illustrates how large citizen science datasets can become.
  • C. Yes, after the first sentence, because it provides a concrete example that illustrates the range and longevity of citizen science programmes described in the opening claim.
  • D. No, because the paragraph's focus is on scientific capacity and public engagement, and the history of one specific programme is a distraction.
C. The first sentence makes a general claim about citizen science expanding scientific capacity across multiple fields. The Audubon Count illustrates this with a specific example — ornithology, which is one of the mentioned fields, and the "over a century" detail supports "significantly expanded" and "large datasets." C correctly identifies it as an illustration of the opening claim. B is tempting — the large dataset point fits — but the sentence's primary information (begun in 1900, bird count, over a century) is better placed right after the general claim than after the dataset-size sentence. D is wrong — the example directly illustrates the main claim.
Practice 4 — Revise with goal
Sleep deprivation has serious consequences. Studies have documented numerous negative effects on cognition and physical health in sleep-deprived individuals.
The student wants to revise the underlined portion to be more specific and persuasive about the scale of the problem. Which revision best accomplishes this goal?
  • A. Research suggests that not sleeping enough may be bad for you in various ways.
  • B. Some studies have found that sleep-deprived people do not perform as well on certain tasks.
  • C. Studies have found that sleeping fewer than six hours per night impairs memory consolidation, reduces reaction time by up to 20%, and increases the risk of cardiovascular disease.
  • D. Scientists who study sleep have published research showing that sleep deprivation affects many different body systems in ways that are currently being investigated.
C. Goal: more specific AND more persuasive about scale. C gives specific thresholds (fewer than six hours), specific effects (memory, reaction time), specific magnitude (up to 20%), and a specific risk (cardiovascular disease). A is LESS specific than the original. B is vague (some studies, not perform as well, certain tasks). D is verbose and non-committal ("ways that are currently being investigated").
Practice 5 — Hard: keep or delete with competing justifications
The Amazon rainforest plays a critical role in regulating global climate by absorbing vast quantities of carbon dioxide. Deforestation releases this stored carbon back into the atmosphere, contributing directly to rising greenhouse gas levels. [Brazil's Amazon region is home to approximately 40,000 plant species, 1,300 bird species, and 3,000 types of fish, many of which are found nowhere else on Earth.] At current rates of deforestation, researchers estimate that the Amazon could cross a "tipping point" within the next decade, beyond which it would begin releasing more carbon than it absorbs.
Should the underlined sentence be kept or deleted?
  • A. Kept, because the biodiversity of the Amazon reinforces its importance as a conservation target.
  • B. Kept, because the biodiversity statistics strengthen the case for protecting the Amazon from deforestation.
  • C. Deleted, because the paragraph's focus is on the Amazon's role in climate regulation through carbon absorption, and the biodiversity statistics do not serve that specific argument.
  • D. Deleted, because the biodiversity data is inaccurate.
C. This is the hardest type: A and B both make plausible arguments for keeping it. The key is the paragraph's SPECIFIC main point — carbon absorption and climate regulation. The biodiversity statistics are genuinely interesting and supportive of conservation broadly, but the paragraph is making a narrow climate argument, not a biodiversity argument. The sentence introduces a different supporting rationale (biodiversity) that isn't the paragraph's focus. D invents a factual error not present in the passage.

Summary card
Keep this
Add · Delete · Revise · Placement — Everything you need
The one rule
State the paragraph's main point first. Then ask: does this sentence DIRECTLY serve that specific main point? Not: is it interesting? Not: is it related to the topic?
Delete test
"What would the paragraph lose if this sentence were removed?" If the main point survives intact → delete. If essential mechanism/evidence is lost → keep.
Placement rule
The sentence must come AFTER whatever it refers back to ("this discovery," "the observation") and BEFORE whatever it introduces or sets up. Pronouns must have antecedents that precede them.
Revise with goal
Same as rhetorical synthesis — goal verb first. "More specific" = add precise numbers/examples. "More persuasive" = stronger claim with evidence. "Introduce" = define + context.
Trap — the biggest one
"Interesting and related to the topic" is NOT a reason to keep. "Supports conservation" is NOT the same as "serves this paragraph's specific climate argument." Match the sentence to the paragraph's narrow point.
Wrong deletion reasons
Never delete because: "the information is inaccurate" (unless actually false) or "the author disagrees" (not stated). Only delete because: doesn't serve the main point.
